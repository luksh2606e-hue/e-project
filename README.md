# Alpine Ascents

A responsive React recreation of the Alpine Ascents educational mountaineering site, with GSAP scroll reveals, a persistent light/dark theme toggle, interactive navigation, gallery, and preparation checklist.

## Run locally

1. Install Node.js 20 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed in the terminal.
4. Run `npm run build` to create the production build in `dist/`.

Photography loads from Unsplash and therefore requires an internet connection. The site is an educational recreation; technical climbing skills should be learned from qualified instructors.
